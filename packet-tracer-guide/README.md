# First network

The network built in the [Packet Tracer Guide](https://www.yuval.guide/ccna/packet-tracer-guide/).

| Device | Port | Address | Connected to |
| --- | --- | --- | --- |
| Router | GigabitEthernet0/0 | 192.168.1.1/24 | Switch GigabitEthernet0/1 |
| PC0 | FastEthernet0 | 192.168.1.10/24 | Switch FastEthernet0/1 |
| PC1 | FastEthernet0 | 192.168.1.11/24 | Switch FastEthernet0/2 |

Both PCs use 192.168.1.1 as their default gateway.

- `first-network.pkt`: the network.
- `router.txt`: the router's running configuration.
